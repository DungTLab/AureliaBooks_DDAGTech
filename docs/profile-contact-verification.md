# Profile contact verification

The account policy changed on 12 October 2026. The earlier current-email/current-phone OTP authorization flow has been replaced.

Confirm the local password, or authenticate the same linked Google identity for a Google-only account; then verify an OTP sent to the destination email or phone before saving. Existing unverified contacts can be verified through the same flow. Successful changes retain uniqueness, record audit and require sign-in again.

See [Account registration and recovery](account-security-v2.md) for source components, Google linking, OTP limits, configuration and deployment limitations.
